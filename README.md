# 🎬 Movie Browser App

A modern Android app built with **Kotlin**, **Jetpack Compose**, **Paging 3**, **Hilt**, and **Coroutines + Flow**.  
The app allows users to browse popular movies, search by title, and view detailed movie information — following **MVVM Clean Architecture** principles.

---


## 🚀 Features

✅ Browse popular and top-rated movies  
✅ Infinite scrolling using **Paging 3**  
✅ Movie search with dynamic results  
✅ Detail screen with poster, overview, rating  
✅ Add/remove **Favorites**  
✅ Offline caching with Room (optional extension)  
✅ Modern UI with **Jetpack Compose (Material 3)**  
✅ Dependency injection via **Hilt**  
✅ Reactive data using **Flow** and **StateFlow**

---

## 🧱 Architecture

Clean MVVM layered architecture with reactive data flow.
